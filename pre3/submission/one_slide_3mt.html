Three-Minute Thesis

Finding similar graphs, faster

Machine learning + smart indexing: like a librarian who knows which shelves to search first.

The everyday problem

In real databases, we often need things that are close enough, not exact copies.

Checking every candidate one by one is accurate, but too slow.

The research idea

First narrow the search, then check carefully.

1. Learnestimate which graphs look close
2. Narrowuse an index to avoid wasted search
3. Checkverify the best candidates

Why it matters

A smarter search system can save time without missing useful matches.

Drug discovery Find molecules with similar structures more efficiently.
Biology and networks Compare complex structures when exact matching is unrealistic.
Software analysis Detect similar program patterns in large code collections.
Aim: a fast, scalable, and reliable graph search framework.
Core message: know where to look first, then check carefully.

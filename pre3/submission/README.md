# Presentation 3 Submission

This folder contains the working submission files for MCCP6020 Presentation 3: Three-Minute Thesis.

## Files

- `one_slide_3mt.html` - one static, machine-readable HTML slide.
- `design_and_story.md` - explanation of slide design and non-specialist storytelling choices.
- `recording_note_cards.md` - keyword prompts for practising and recording the audio; not a script to read aloud.
- `audio_link.md` - placeholder for the final audio file or hosted audio link.

Machine Learning for Graph Similarity Search

Toward a unified framework for efficient, scalable, and high-recall retrieval in graph databases.

Author: GOU Jiajie | Course: MCCP6020 | Format: HTML poster for Pre2 submission

Research snapshot

  • Problem: exact graph edit distance is powerful but computationally expensive.
  • Gap: existing ML methods often improve only one part of the retrieval pipeline.
  • Aim: combine learned approximate distances with metric-space indexing in one framework.
1. Background and problem

Why graph similarity search matters

Graph similarity search retrieves graphs that are close to a query graph rather than exactly the same. This matters in bioinformatics, chemoinformatics, software engineering, and computer vision.

Bioinformatics Chemoinformatics Software engineering Computer vision
  • Graph edit distance (GED): the minimum number of edits required to transform one graph into another.
  • Key challenge: exact GED is NP-hard, so large-scale search becomes expensive.
  • Main concern: systems must balance recall, speed, memory use, and scalability.

2. Research gap

Why a new framework is needed

  • Embedding- and hashing-based methods can filter quickly, but may weaken in recall or become costly at large thresholds.
  • Approximate GED methods can accelerate pairwise comparison, but are often studied outside a full end-to-end retrieval pipeline.
  • Hybrid systems are promising, yet the integration of learned components with metric-space indexing is still limited.

My central argument is that no single method solves the whole problem. The field needs a more integrated design.

3. Objectives and research questions

What this study aims to do

  • Objective 1: survey and synthesise current ML-based approaches to graph similarity search.
  • Objective 2: investigate how learned components can be integrated with metric-space indexing.
  • Objective 3: design and evaluate a unified framework for efficient, high-recall retrieval.
Research focus: how can machine learning and indexing work together, rather than separately, in large graph databases?
4. Literature synthesis

Three themes in the literature

Filtering and indexing

Examples: GHashing, LAN

Strength: reduce the number of exact comparisons.

Limitation: recall-efficiency trade-offs can worsen when the threshold grows.

Approximate GED

Examples: App-BMao, GEDHOT, GREED

Strength: faster pairwise similarity estimation.

Limitation: often not evaluated in full retrieval pipelines.

Hybrid and two-stage

Example: Gisma

Strength: bridge theoretical indexing and learned estimation.

Limitation: design choices and scalability remain underexplored.

Preliminary insight from my literature review: the strongest future direction is integration, not isolation.

7. Hypotheses and anticipated findings

What I expect to find

  • H1: integrated learned-plus-indexed systems will improve end-to-end efficiency over isolated methods.
  • H2: hybrid methods will preserve recall better at larger thresholds and database scales.
  • H3: systematic comparison will produce practical guidance for choosing methods under different retrieval goals.

Because the project is still at proposal stage, this poster reports literature-based preliminary insights and anticipated findings rather than completed experimental results.

8. Significance and contribution

Why this research is worthwhile

  • Provides a clear map of machine learning approaches for graph similarity search.
  • Bridges theoretical indexing ideas with practical ML-enhanced retrieval design.
  • Supports scalable search in chemistry, biology, and software analysis.
  • Builds a foundation for future systems that are both efficient and effective.
9. Conclusion

Main takeaway

Machine learning is already important in graph similarity search, but my poster argues that the most promising direction is a unified framework that combines learned components with robust indexing and systematic evaluation.

Key message: better graph similarity search is not only about a faster model; it is about a better search system.

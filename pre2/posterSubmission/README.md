# Pre2 Poster Submission

This folder contains a machine-readable poster submission package for Presentation 2.

## Files

- `poster.html`
  - main poster file
  - machine-readable HTML
  - suitable for browser viewing, GitHub Pages, and printing

- `outlineScript.md`
  - 2-3 minute note-card style speaking outline
  - intended for practice and recording support
  - not a script to read aloud

- `anticipated_QA.md`
  - anticipated questions and bullet-point replies
  - useful for both preparation and assessment evidence

- `audio_link.md`
  - placeholder for the final audio URL
  - use this if the audio is uploaded to GitHub or hosted elsewhere

- `forum_reply_template.md`
  - ready-to-edit Moodle forum reply template
